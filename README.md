# Palindrome Checker

A C++ program that determines whether a C-style string (C-string) is a palindrome using a stack and a queue. This project demonstrates the use of fundamental data structures to process and compare character sequences.

# Features

Checks whether a C-string is a palindrome

Uses a stack to process characters in reverse order

Uses a queue to process characters in their original order

Compares characters to determine whether the string reads the same forward and backward

# How to Run (Visual Studio)

Download the repository as a ZIP file from GitHub.

Extract the ZIP file to a convenient location.

Open the extracted folder and locate the .sln file.

Double-click the .sln file to open the project in Visual Studio.

In Visual Studio, select Debug → Start Without Debugging to build and run the program.
